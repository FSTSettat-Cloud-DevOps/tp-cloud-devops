# Consignes de remise du compte rendu — TP 1–2

Bonjour,

Pour réaliser le compte rendu du **TP 1–2 : Premier contact avec une infrastructure Cloud locale**, téléchargez le fichier `COMPTE_RENDU_TP1-2_TEMPLATE.md` disponible sur GitHub.

1. Renommez le fichier en `COMPTE_RENDU_TP1-2_Nom_Prenom.md`.
2. Complétez toutes les sections, les tableaux et les questions de réflexion.
3. Ajoutez les captures d'écran correspondant aux manipulations réellement effectuées.
4. Placez les captures dans un dossier `captures/` et vérifiez les chemins des images dans le fichier Markdown.
5. Déposez le compte rendu et les captures dans votre dépôt GitHub personnel.

> **Important :** les réponses et les résultats doivent correspondre à votre propre travail. Ne remettez pas uniquement le modèle vierge.

## Structure recommandée du dépôt

```text
Depot-Etudiant/
├── README.md
├── COMPTE_RENDU_TP1-2_Nom_Prenom.md
└── captures/
    ├── 01-vagrant-box-list.png
    ├── 02-vagrant-status.png
    ├── 03-identite-vm.png
    ├── 04-ressources-vm.png
    ├── 05-ssh-status.png
    ├── 06-tests-reseau-ssh.png
    ├── 07-ufw-regles.png
    ├── 08-utilisateur-groupe.png
    ├── 09-vagrant-up.png
    └── 10-vagrant-ssh.png
```

Les noms des captures sont proposés à titre indicatif. Si vous les modifiez, mettez également à jour les chemins des images dans le fichier Markdown.

Avant de remettre votre travail, vérifiez que le compte rendu et toutes les captures sont bien visibles dans votre dépôt GitHub.
