# 📁 Consignes de dépôt des travaux pratiques (TP) – DevOps

Chaque étudiant doit disposer de son propre dépôt GitHub pour déposer les réponses et les captures d'écran associées aux différentes séries de TP.

## 1. Création du dépôt GitHub

Chaque étudiant doit créer un dépôt GitHub personnel portant obligatoirement le nom suivant :

```text
tp-devops-nom-prénom
```

**Exemple :**
```text
tp-devops-abassi-amine
```

Remplacez `nom` et `prénom` par votre nom et votre prénom.

## 2. Organisation du dépôt

À l'intérieur de votre dépôt, vous devez créer un dossier pour chaque série de TP.

La structure doit respecter l'organisation suivante :

```text
tp-devops-nom-prénom/
│
├── serie-01/
│   ├── reponses.md
│   ├── captures/
│   │   ├── capture-01.png
│   │   ├── capture-02.png
│   │   └── ...
│
├── serie-02/
│   ├── reponses.md
│   ├── captures/
│   │   ├── capture-01.png
│   │   └── ...
│
├── serie-03/
│   ├── reponses.md
│   └── captures/
│
└── README.md
```

Vous devez respecter les règles suivantes :

- Créer un dossier distinct pour chaque série : `serie-01`, `serie-02`, `serie-03`, etc.
- Déposer les réponses aux questions dans un fichier Markdown nommé `reponses.md`.
- Déposer les captures d'écran demandées dans un sous-dossier nommé `captures`.
- Associer chaque capture à la question correspondante.
- Utiliser des noms explicites pour les captures d'écran (exemple : `question-01.png`, `question-02.png`).

## 3. Travail en binôme

Même si le TP est réalisé en binôme, **chaque étudiant doit déposer sa propre copie dans son dépôt GitHub personnel**.

Ainsi :
- Les deux étudiants peuvent travailler ensemble et partager leurs connaissances.
- Chaque étudiant doit disposer de son propre dépôt.
- Chaque étudiant doit déposer ses propres réponses et captures d'écran dans son dépôt personnel.

**Important :** Un seul dépôt partagé entre les deux étudiants n'est pas accepté.

## 4. Vérification avant le dépôt

Avant de considérer votre travail comme terminé, vérifiez que :

- [ ] Le dépôt porte le nom demandé : `tp-devops-nom-prénom`.
- [ ] Un dossier est créé pour chaque série de TP.
- [ ] Les réponses sont enregistrées dans un fichier `reponses.md`.
- [ ] Toutes les captures d'écran demandées sont présentes.
- [ ] Les captures sont placées dans le dossier `captures`.
- [ ] Les modifications ont été envoyées sur GitHub (*Commit & Push*).

## 5. Remarque importante

Le dépôt GitHub constitue votre espace personnel de remise des travaux pratiques. Veillez à maintenir une organisation claire et à jour tout au long du module.

**Tout travail doit être déposé dans le dépôt personnel de l'étudiant.**
